<h2 align="center">About Me 🚀</h2>

<p align="center">I'm a final-year Software Engineering student at UIT - VNUHCM with hands-on experience as a Software Engineering Intern, passionate about building reliable, scalable, and maintainable software. My programming journey started from scratch during my first year at university, and since then I've continuously challenged myself to learn through real-world projects, self-study, and practical experience.

My strongest foundation is in backend development, where I work primarily with ASP.NET Core, Entity Framework Core, PostgreSQL, SQL Server, Node.js, and Express.js. Throughout projects such as SmashCourt, VetFeed, and Wedding Management System, I've focused not only on delivering functional applications but also on designing systems that are structured, maintainable, and built with long-term scalability in mind.

What drives me most is understanding how software works beneath the surface. I enjoy analyzing execution flows, exploring how different components communicate, and solving complex problems through logical thinking. For me, writing code is more than implementing features—it's about understanding the architecture, the reasoning behind every decision, and building systems that remain reliable as they evolve.

I believe software engineering is a discipline built on standards rather than shortcuts. Clean Architecture, consistent coding practices, well-defined design patterns, and thoughtful system design are principles I strive to follow in every project. My goal is never to make software simply "work," but to create codebases that are readable, maintainable, and easy for others to understand and extend.

While backend engineering is currently my strongest expertise, I see it as only one part of becoming a complete software engineer. My ambition is to continuously expand into frontend development, system design, cloud technologies, DevOps, and distributed systems, enabling me to build high-quality solutions across the entire software development lifecycle.

I'm always eager to learn new technologies, but I believe every tool should serve a clear purpose. Technology should solve real problems, architecture should support long-term growth, and every engineering decision should be intentional. Over the next five years, my goal is to become a well-rounded Software Engineer who combines strong technical expertise with structured thinking to build software that is both impactful and built to last.
</p>
